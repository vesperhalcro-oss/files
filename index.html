Overview

Built for simulation, telemetry, and local map generation

Mock LiDAR stream

Simulates a moving vehicle and live scan data to demonstrate how a foveated mapping system could interpret range and motion cues.

Live map

Updates the visualized environment as the vehicle moves, helping track path, occupancy, and throughput locally without external services.

Embedded SQLite

Stores telemetry and event data in a local database so the project remains portable and self-contained on a Windows workstation.
