Overview

Built for simulation, telemetry, and local map generation

Dataset replay

Replays a checked-in point cloud through the same foveated mapping path used by the native prototype.

Live map

Updates the visualized environment as the vehicle moves, helping track path, occupancy, and throughput locally without external services.

Local PostgreSQL

Persists frames and semantic 2.5D cells asynchronously to a local PostgreSQL instance without blocking rendering.
